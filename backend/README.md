# OliveFlow Backend

API REST Express + PostgreSQL pour la gestion des معاصر الزيتون.

## Setup

```bash
npm install
# Créer la DB PostgreSQL puis :
npm run db:init
npm run db:seed
npm run dev
```

API: http://localhost:4000/api/v1  
Health: http://localhost:4000/health
